# MIP-C01: Powders & Wet Granulation – Batch Record (Web-App)

Digitaler Batch-Record LMI PD01 für den Praktikumsversuch MIP-C01 (M.Sc. Industrial Pharmacy, HHU Düsseldorf).

**App öffnen:** über die GitHub-Pages-Adresse dieses Repositorys (Settings → Pages).

- **iPad:** Adresse in Safari öffnen → Teilen-Symbol → „Zum Home-Bildschirm“.
- **Android:** Adresse in Chrome öffnen → Menü ⋮ → „App installieren“.
- **Laptop:** Adresse in Chrome/Edge öffnen → Installieren-Symbol in der Adressleiste (optional).

Alle Eingaben bleiben auf dem jeweiligen Gerät; es werden keine Daten an einen Server übertragen.
Sicherung und Weitergabe über **Save** (.json-Datei), Laden über **Open**.
Die .json-Dateien sind mit der Windows- und Mac-App austauschbar.

**Update:** neue `index.html` hochladen und in `service-worker.js` die Versionsnummer in `CACHE` erhöhen.
